# ADR-0004: Pin state lives in a `.sheaf/meta.json` sidecar

- Status: accepted (2026-08-25)
- Context: pinning needs per-note state, but ADR-0001 keeps note files
  pristine and portable. YAML frontmatter would rewrite every pinned file and
  make plain editors see noise.
- Decision: pins live in `<vault>/.sheaf/meta.json`
  (`{"pinned": [vault-relative paths]}`), written only by `VaultRepository`.
  Renames move the pin; deletions drop it. A corrupt or missing file recovers
  to an empty set — pins are a convenience, never a reason to refuse a vault.
- Consequences: one more dot-directory in the vault contract (`.trash/`
  precedent); external editors ignore it; copying notes between vaults does
  not carry pins (acceptable at v0.2 scale).

# ADR-0005: Zoom is app-wide text scaling, not pixel chrome scaling

- Status: accepted (2026-08-25)
- Context: users expect browser-style zoom (`Ctrl+=` / `Ctrl+-`). Flutter
  re-renders text crisply at any scale, but scaling painted icons/pixels would
  blur them; there is no first-class whole-UI zoom.
- Decision: zoom is a single persisted multiplier (50–200%, 10% steps with
  float-drift snapping) applied as an inherited `TextScaler` at the app root.
  Every text surface scales together; fixed-dp icons/dividers intentionally do
  not. The settings' editor font size tunes note-body type independently.
- Consequences: mixed density at high zoom (large text, constant icons) —
  judged acceptable versus blurring; revisit if icon scaling becomes a theme
  concern.

# ADR-0006: Theme worlds are curated in code

- Status: accepted (2026-08-25)
- Context: story 16 wanted more looks than Quire's two modes. Parsing local
  GTK theme CSS was considered and rejected as fragile; third-party toast/
  seed packages were rejected for fidelity and dependency cost.
- Decision: a world registry (`lib/theme/worlds.dart`) maps stable ids to
  hand-tuned light/dark token palettes built through the same `buildTokens`
  path as Quire. Launch set: Quire, Graphite, Sepia. Unknown persisted ids
  fall back to Quire. All colors live inside `lib/theme`; nothing else reads
  hex.
- Consequences: new worlds are code changes (by design); system accent color
  still flows through `dynamic_color` for Material You surfaces on Android.
